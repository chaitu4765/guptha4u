# Visual direction
An independent Guptha Arts retail workspace, informed by er4u's violet identity. Desktop sidebar, compact white work surfaces, violet navigation and primary buttons, warm neutral canvas, restrained green status labels. Actual business data drives all charts and totals. Art supply category names guide catalog entry without inventing stock.
Responsive: collapsible navigation, scrolling tables, stacked POS panels on small screens. Visible labels, focus states, native validation and useful empty states.
